# ADR-015 — Escrita offline e sincronização

- Situação: Fora da versão inicial
- Data: 2026-09-21

## Contexto

Material antigo previa operação offline no Mac.

## Decisão

Não incluir. Rede local sem internet externa atende o requisito de independência de internet.

## Consequências

Nova decisão explícita do usuário seria necessária para reabrir.

## Alternativas consideradas

Sincronização bidirecional com resolução de conflitos.
