# ADR-014 — IA generativa externa

- Situação: Futuro — desativado
- Data: 2026-09-25

## Contexto

IA é evolução futura.

## Decisão

Porta de IA inicialmente desligada; dados permitidos, provedor, retenção e credencial exigem decisão explícita. IA não executa ação financeira; cálculos vêm do motor.

## Consequências

Nenhuma dependência de IA no núcleo.
