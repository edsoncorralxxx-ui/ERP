# Registros de decisão (ADR)

Cada ADR registra contexto, decisão, consequências e alternativas. Situações: Aceito (decisão do usuário ou aprovada), Proposto (recomendação aguardando aceite), Pendente (sem decisão), Futuro/Fora da versão.

Um ADR Proposto orienta o trabalho, mas não equivale a aprovação. A lista original de decisões está em `docs/backend/09-decisoes-e-pendencias.csv`; ADR-016 foi acrescentado no B01.
