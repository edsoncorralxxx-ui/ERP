Etiqueta ao lado de um campo que mostra um valor preenchido ou previsto pela IA.

- Marcação: `<span class="rp-ai-hint"><i class="rp-ico rp-ico-ia-…"></i><b>IA</b> texto curto</span>` à direita do campo.
- O campo sugerido fica em `field-active` até o usuário confirmar (Tab ou Enter).
- Diga de onde veio ("com base em 42 lançamentos").
