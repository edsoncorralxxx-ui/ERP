Colunas empilhadas com profundidade: o total de cada período e a participação de cada série na mesma coluna.

- Script: `RendaERP.Empilhadas3D(elemento, {categorias, series:[{nome, valores}], largura, altura, profundidade, unidade})`.
- Use quando o total importa tanto quanto a divisão; se só a comparação entre séries importa, use Barras 3D.
- No máximo quatro séries — acima disso a leitura das fatias do meio se perde.
- Passe o mouse sobre um bloco para ver a série, o período e o valor exato.
