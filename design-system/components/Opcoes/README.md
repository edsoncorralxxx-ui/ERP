Caixas de seleção e botões de rádio, com o rótulo à direita.

- Marcação: `<label class="rp-choice"><input type="checkbox"> Rótulo</label>` (ou `type="radio"` com `name` comum).
- Caixas de seleção empilhadas na vertical para indicadores independentes (Item de estoque / venda / compra).
- Rádios empilhados na vertical para o estado do registro (Ativo / Inativo / Avançado), sempre embaixo à esquerda da aba Geral.
