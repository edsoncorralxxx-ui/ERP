Ícones das análises com IA: cada um é um ícone do sistema com a faísca dourada de quatro pontas, a marca da IA.

- `ia-insight` descoberta/insight · `ia-previsao` previsão de tendência · `ia-anomalia` desvio fora do padrão · `ia-assistente` conversa com o assistente · `ia-recomendacao` sugestão de ação · `ia-resumo` resumo de documento · `ia-risco` risco de crédito ou fraude · `ia-classificacao` categorização automática · `ia-analise` análise de dados · `ia-automacao` regra automatizada.
- A faísca é reservada à IA: nenhum outro ícone a usa, e todo conteúdo gerado por IA mostra um destes ícones ou o selo `rp-badge--ia`.
- Versão branca `rp-ico-w-NOME` para fundos azuis.
