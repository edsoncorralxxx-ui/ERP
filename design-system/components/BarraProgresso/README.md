Barra segmentada para processos longos (importação, fechamento, análise de IA).

- Marcação: `.rp-progress[role=progressbar]` com um `span` cuja largura é o percentual; em linha com rótulo e valor dentro de `.rp-progress-row`.
- Em andamento: `nav-selected` segmentado; concluído: `rp-progress--ok` (`status-success`).
- Sempre mostre o percentual em texto ao lado.
