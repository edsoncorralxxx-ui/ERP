Linha de saldo do cabeçalho de um parceiro de negócios: seta dourada, valor calculado e botão de gráfico.

- Marcação: `.rp-label.rp-link-field` com a `.rp-link` antes do texto + `.rp-saldo` com o `input.rp-field.rp-field--num.rp-field--readonly` e o `button.rp-graf-btn`.
- O valor é sempre calculado: cinza (`field-readonly`), à direita, duas casas, nunca editável nem com foco.
- A seta dourada abre a lista que forma o número (lançamentos, entregas, pedidos); o botão de gráfico abre o mesmo número no tempo. São dois caminhos diferentes — mantenha os dois.
- Use no canto superior direito da janela de dados mestre, alinhado com os campos do cabeçalho: Saldo da conta, Entregas, Pedidos, Oportunidades.
- Contagem (Oportunidades) vai sem casas decimais; dinheiro vai com duas.
