Duas dicas diferentes: a da barra de ferramentas, curta e clara, e a nota amarela que explica um campo.

- **Dica de ferramenta** — `<span class="rp-tip rp-tip--ferramenta" role="tooltip">Visualizar...</span>`: uma linha só, fundo `chrome`, borda `window-border`, aparece logo abaixo e à direita do ponteiro. É o nome da ação, com reticências quando ela abre outra janela. Todo botão da Barra de ferramentas tem a sua.
- **Nota de campo** — `<span class="rp-tip" role="tooltip">…</span>`: caixa `field-note` de uma ou duas frases, para explicar o que entra no campo ou o que o número significa.
- Nenhuma das duas é o único lugar de uma informação necessária.
