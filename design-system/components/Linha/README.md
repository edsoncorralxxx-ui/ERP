Linhas com marcadores, em duas dimensões, para séries longas onde o 3D atrapalharia a leitura.

- Script: `RendaERP.Linha(elemento, {categorias, series:[{nome, valores}], largura, altura, unidade})`.
- Use para tendência ao longo do tempo (saldo, consumo, horas apontadas, aderência ao plano); para comparar poucos períodos, prefira Barras 3D.
- Até quatro séries e 24 pontos. Os marcadores trazem o valor exato ao passar o mouse.
- Não misture linha e barra no mesmo desenho; se precisar de duas escalas, use dois cartões lado a lado.
