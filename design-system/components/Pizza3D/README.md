Gráfico de pizza inclinado com espessura, para participação de até 5 partes.

- Script: `RendaERP.Pizza3D(elemento, {fatias:[{nome, valor}], largura, altura, profundidade})`.
- Fatias em `chart-1` a `chart-5`; percentuais em ink sobre as fatias maiores; legenda à direita.
- Use só para partes de um todo; para comparar períodos use Barras 3D.
