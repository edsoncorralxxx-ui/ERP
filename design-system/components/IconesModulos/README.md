Um ícone por módulo do ERP, em cores (listas, cockpit) e em branco (`rp-ico-w-NOME`) para o Painel de módulos.

- Nomes: administracao, financas, oportunidades, vendas, compras, parceiros, bancos, estoque, producao, mrp, servico, rh, relatorios.
- Sobre `nav` ou `nav-selected`, use sempre a versão branca.
