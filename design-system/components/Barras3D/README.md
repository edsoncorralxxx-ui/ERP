Gráfico de barras agrupadas com profundidade, no estilo dos relatórios clássicos (paredes, piso e barras com topo e lateral).

- Script: `RendaERP.Barras3D(elemento, {categorias, series:[{nome, valores}], largura, altura, profundidade, unidade})`.
- Cores das séries: `chart-1` (amarelo), `chart-2` (verde), `chart-3` (lilás), `chart-4`, `chart-5`; o topo clareia e a lateral escurece automaticamente.
- Até 4 séries e 12 categorias. Valores no eixo em formato brasileiro; passe o mouse sobre a barra para ver o valor exato.
- Coloque dentro de `.rp-chart` com `.rp-chart-head` (ícone, título, Seleção do tipo de gráfico).
