Lista de seleção em duas colunas, para escolher e ordenar conjuntos: colunas de uma grade, campos de um relatório, permissões de um perfil.

- Marcação: `.rp-lista-dupla` > lista `.rp-lista` + `.rp-lista-mover` com quatro botões + a segunda `.rp-lista`.
- Item marcado em `nav-selected` com texto branco; hover em `field-active`. A lista rola com a barra clássica (`rp-rolagem`). Aceite seleção múltipla com Ctrl e Shift e duplo clique para mover.
- Os botões usam apenas os sinais ‹ › » «, na ordem adicionar, adicionar todas, remover, remover todas.
- A lista da direita é ordenável (arraste ou Alt+Setas) quando a ordem tiver significado — diga isso no rótulo: "Colunas exibidas (na ordem)".
- Para uma escolha só, use Seleção (lista suspensa); para poucas opções fixas, Opções.
