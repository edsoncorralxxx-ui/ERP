Etiqueta compacta com o estado de um documento ou item, com ponto colorido e palavra.

- Marcação: `<span class="rp-badge rp-badge--ESTADO">Palavra</span>`; estados: `aberto`, `pendente`, `aprovado`, `fechado`, `cancelado`, sem modificador = rascunho, `ia` = resultado gerado por IA.
- A palavra é obrigatória: a cor nunca aparece sozinha.
- Use na coluna Status das grades e no cabeçalho de documentos.
