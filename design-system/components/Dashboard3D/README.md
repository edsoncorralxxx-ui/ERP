Cockpit de exemplo que combina os componentes: barra de menus, barra de ferramentas, indicadores, gráficos 3D, análise com IA e barras de status.

- Estrutura: `.rp-dash` > `.rp-dash-kpis` (4 Indicadores) > `.rp-dash-row` (gráfico largo + gráfico estreito ou painel de IA), espaçamento `space-5`.
- A janela do cockpit segue o componente Janela; o rodapé usa Barra de status e Barra de status do sistema.
- Um painel de IA por dashboard, sempre à direita; no máximo três gráficos 3D por tela.
