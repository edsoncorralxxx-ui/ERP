Campo com lista suspensa e triângulo preto à direita; mesma caixa, altura e estados do Campo de texto.

- Marcação: `<div class="rp-select"><select class="rp-field">…</select></div>`; quem consome fornece as opções.
- Use para listas fechadas (Grupo, Moeda, Tipo de item). Para listas que o usuário amplia, coloque uma Seta de link antes do rótulo.
