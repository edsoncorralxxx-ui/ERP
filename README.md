# Renda+ ERP

ERP industrial orientado a projetos para a Fourtech/Renda+. Cliente macOS em Electron + React; servidor em Java + Python.

Situação: planejamento e especificação. Ainda não há código executável do servidor ou do cliente neste repositório.

## Onde começar

- `docs/backend/00-LEIA-ME.md` — pacote de planejamento do backend (fases B01–B16).
- `docs/backend/02-roteiro-e-backlog.md` — roteiro; `docs/backend/04-prompts-implementacao.md` — protocolo de execução.
- `docs/backend/progresso.md` e `docs/backend/backlog-execucao.md` — estado real da execução.
- `docs/adr/` — decisões de arquitetura.
- `docs/` — plano funcional, estudo dos PDFs, pesquisa técnica, interface por janelas e briefing de design.

## Precedência

Instruções explícitas do usuário → decisões registradas e aceitas (ADRs) → plano funcional vigente → detalhamento proposto do backend → exemplos do mock e arquivos históricos. JavaFX/SQLite e escrita offline citados em material antigo não foram adotados.
